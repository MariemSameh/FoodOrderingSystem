Fast Food Ordering System (.NET 7 MVC)
This project is a fully functional fast food ordering website built with .NET 7 and ASP.NET Core MVC. It provides a user-friendly interface for customers to browse Restaurants, place orders, and track deliveries.
*Features*:

  - Menu Browsing: View available restaurants and their respective menus with detailed item descriptions.
  - Delivery Management: Includes features for managing delivery personnel and optimizing delivery routes.

*Technical Details*:

  - Framework: .NET 7, ASP.NET Core MVC
  - Database: (Entity Framework Core, SQL Server)
  - Frontend: (HTML, CSS, Bootstrap, JavaScript libraries)
